# Artwork handling

The website's monochrome SVG silhouette was extracted from the existing supplied transparent `garuda_sun_emblem_with_khaga_wordmark.png` asset. It was not regenerated by an image model. `public/brand/khaga-master.svg` is the single source used for the header/footer wordmark, emblem and garment illustration marks. The wordmark is cropped from that same artwork, not reset in another font.

The original glossy “01 SIGNATURE (PRIMARY)” image remains the visual reference for brand approval. The monochrome SVG is a web derivative, not a certified production embroidery file. Any final logo refinements should update this single asset and be approved before manufacturing.

Product images are scalable concept illustrations based on the agreed layouts. The front/back arrangement changes between products, but the underlying emblem path does not. Solar's separate decorative rays do not replace the core sun/halo symbol. Colours are proposals and do not assert physical stock or dye matching.

The campaign uses a crop of the existing Ascent lookbook showing front and back garment concepts. No outside model imagery, third-party fonts or unrelated product photographs were added. Final commerce photos still need physical sample approval.
